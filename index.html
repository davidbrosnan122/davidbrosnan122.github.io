01 / PROJECTS

Selected work

A selection of projects I’ve worked on, from mobile apps to document tools.

01AI / WEB

Company document search

A chat tool that searches company documents and support guides. A Python backend finds relevant passages, and an LLM API uses them to answer questions with links to the source documents.

The React interface includes chat history and filters. Access is limited by user permissions, and background updates keep documents searchable. Tests cover missing and conflicting information.

React · Python · PostgreSQL · LLM API

02MOBILE

Meal logging & nutrition

An iOS and Android app for recording meals and tracking nutrition. Users can describe meals in their own words and correct estimated calories and nutrients.

Entries are saved offline and synced when the connection returns. The app includes daily summaries, reminders, and weekly charts, with tests for portion sizes and time zones.

React Native · TypeScript · Node.js

03VR / TRAINING

Installation training in VR

A Unity app for practicing installation tasks with tool selection, step-by-step instructions, and progress checks. A Python API and dashboard help trainers review completed steps and missed tasks.

Actions and timing are recorded, and session data is stored locally during connection problems and uploaded afterward.

Unity · C# · Python

04DESKTOP

Document organizer & cloud sync

An Electron app for organizing documents and syncing files, with search, upload queues, and transfer progress. Cloud-storage APIs check for new and changed files.

Uploads can resume after a pause. The app handles duplicates, conflicting versions, and connection retries, while keeping document contents out of error logs.

Electron · React · Node.js

05MOBILE / OPERATIONS

Appointment booking & job assignments

A Flutter app where customers request appointments and staff assign jobs based on technician availability. Firebase handles accounts, data, and notifications.

Separate permissions support customers, technicians, and office staff. Checks prevent double bookings, and upcoming jobs can be viewed offline.

Flutter · Firebase
