A few projects

A selection of applications and tools I’ve worked on.

01 SEARCH / AI

Finding answers in company documents

A chat tool for searching documents and support guides. A Python and PostgreSQL backend finds relevant passages, and an LLM API produces answers linked to their sources.

The React interface has chat history and search filters. Access is limited by user permissions, and background updates keep new documents searchable. Tests cover missing or conflicting information.

ReactPythonPostgreSQLLLM API

02 MOBILE / HEALTH

Keeping a meal journal

An iOS and Android app for logging meals and tracking nutrition. People can describe meals in their own words, then correct estimated calories and nutrients.

Entries are saved offline and synced when a connection returns. The app includes daily summaries and weekly charts, with tests for portion sizes and dates across time zones.

React NativeTypeScriptNode.js
↗
03 VR / TRAINING

Practicing installation work in VR

A Unity training app with tool selection, step-by-step instructions, and progress checks. Trainers use a Python API and dashboard to review completed steps, missed tasks, and repeat attempts.

Actions and timing are recorded. Session data is stored locally during connection problems and uploaded afterward.

UnityC#Python
↗
04 DESKTOP / CLOUD

Organizing and syncing files

An Electron application for managing documents across cloud storage, with folders, file search, upload queues, and transfer progress.

Paused uploads can resume. The app checks for duplicate files and conflicting versions, retries connection errors, and keeps document contents out of error logs.

ElectronReactNode.js
↗
05 MOBILE / OPERATIONS

Booking appointments and assigning jobs

A Flutter app where customers request appointments and staff assign jobs based on technician availability. Firebase handles accounts, data storage, and notifications.

Customers, technicians, and office staff have separate permissions. The app checks for double bookings and lets staff view upcoming jobs offline.

FlutterFirebase
